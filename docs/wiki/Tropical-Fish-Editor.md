# Tropical Fish Editor

The **Tropical Fish Editor** is a separate, one-block tank workstation for designing a custom tropical fish without manually searching wild spawns.

## How to use it

1. Craft and place the **Tropical Fish Editor** block.
2. Right-click it with a **Tropical Fish Bucket**. The fish is stored in the block and the editor opens.
3. Select one of the **12 vanilla tropical-fish patterns**.
4. Choose the **body color** and **pattern color** from the two palettes, each containing the **16 Minecraft dye colors**.
5. Use **Swap colors** to exchange the two choices, or **Random** to generate another appearance.
6. Observe the fish swimming in the block with its current appearance.
7. Use an **empty bucket** on the block to retrieve the edited Tropical Fish Bucket.

The pattern chooser indicates whether the selected appearance has a **small** or **large** body. The workstation changes standard Minecraft fish data, so the edited bucket retains the chosen variant.

## Storage and safety

- The editor holds **one tropical fish** at a time.
- Using an empty hand on an occupied or unoccupied editor opens its controls.
- Breaking the workstation returns its block item and, if occupied, its contained Tropical Fish Bucket; Creative break handling also returns these items.
- Editor and Mobitat preview entities have guarded render handling in version 0.7.1 to reduce crashes with third-party entity renderers. Not all third-party renderers are guaranteed compatible.
